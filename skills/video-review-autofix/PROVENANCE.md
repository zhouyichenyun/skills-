# Provenance

Original skill instructions, Python scanner/repairer, handoff mapping and synthetic tests authored for this skill collection on 2026-11-12. No third-party source code was copied.

FFmpeg and FFprobe are external system dependencies, not bundled or relicensed here. Filter and tool references:

- https://ffmpeg.org/ffmpeg-filters.html#blackdetect
- https://ffmpeg.org/ffmpeg-filters.html#freezedetect
- https://ffmpeg.org/ffmpeg-filters.html#silencedetect
- https://ffmpeg.org/ffmpeg-filters.html#loudnorm
- https://ffmpeg.org/ffprobe.html

This package does not include or connect to Jianying/CapCut, DaVinci Resolve, model providers or desktop services. It analyzes local encoded media and writes local reports/new files.
