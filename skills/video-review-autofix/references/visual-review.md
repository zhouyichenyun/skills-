# 真实视觉与声音审核

先读实际输出的报告与成片。只有文件名、脚本参数或创作提示词不构成效果证据。扫描出的帧是定位工具，不替代最终影片播放。

## 审核证据

每项记录 `编码成片路径 / 时间段 / 看到或听到什么 / 影响 / 责任层 / 最小修复 / 复看状态`。未查看写未查看，无法区分写待确认。不虚构质量分、未看的片段或未听过的台词。

先正常速度观看完整片：信息能否一次听懂、删减是否改义、停顿是否必要、节奏是否连贯、素材是否支持讲话。再针对每个切点和发现区间局部放大、慢放或逐帧定位；最后在修复后的实际成片复看。

## 口播与剪口

- 切口前后有无断词、吞辅音、尾音截断、呼吸突变、音量/房间声跳变。
- 删除口头禅或重录段后，否定词、限定条件、数字和逻辑关系有没有丢失。
- 同机位相邻姿态突变是否影响观看；合理时用已核实匹配的 B-roll 覆盖，不用无关素材遮错。
- 口型同步需看实际口部运动并听实际声音；音画流起止相近只是结构线索。

## 字幕

- 实际讲话是否对应字幕；人名、数字、专有词和否定词逐项核对。ASR置信度不能代替对音。
- 看最终烧录版：断行、字号、边距、描边/底板、对比度、竖屏平台界面遮挡、字幕是否盖嘴或重要操作。
- 字幕阅读速度超阈值只是提示；按语义重排或缩短获授权的冗余，不擅改关键台词。
- 外部 SRT 修正之后仍需重烧并复看；旧视频像素不会自动改变。

## B-roll 与 AI 素材

- 素材是否支持同一论点和时间背景；有无把示意/生成画面当作事实证据。
- 覆盖位置是否避开重要口型或肢体演示；进出点、运动方向、声音桥和画幅是否连贯。
- AI画面看脸/手/指头/衣服/道具、人物间遮挡接触、背景几何、文字和标识；首尾一致不等于中间无融化。
- 只有一处瑕疵就定位到该素材和动作拍点，改提示词、换素材或缩短有问题区间，保留已通过部分。
- 素材生成需要实际可用工具与任务授权；审核技能本身不联网、不扣生成额度。

## 调色与观感

- 先确认原片是 Rec.709、Log、HLG/PQ 或其他空间；未知时不套猜测转换。
- 对照中性参考：肤色有无偏橙/绿/灰、白平衡是否合理、亮部有无被压碎或过曝、暗部噪声是否放大。
- 镜间曝光/色温/对比度/饱和度变化是否有动机；用实际示波器/向量示波器证据辅助，不能用元数据替代观感。
- 检查手机竖屏和普通显示条件下字幕、人脸、B-roll是否都可读。
- LUT文件能被生成或应用，不证明达芬奇工程已导入、节点树已执行或显示管理正确。

## 结论边界

- `机器检查通过，视觉/听觉待审`：只完成技术扫描。
- `抽帧已审，完整播放/听觉待审`：证据限于静帧。
- `修复后已复看`：必须记录实际播放/试听范围与残留问题。
- `候选成片`：实际可播放但仍有未解决的审美或内容判断。
- 未完整查看最终编码成片，不写“全片效果合格”。
