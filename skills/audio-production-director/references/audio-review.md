# 音频效果审核与最小返工

先做机器检查：文件可解码、音轨存在、时长与节目相符、采样率/声道、响度与 true peak。静音或不可测保持状态。再实际听审；没有听音工具或未听到的内容标 pending，不能用频谱或测量值代替感知结论。

| 检查 | 需要的证据 | 最小返工 |
| --- | --- | --- |
| 台词、专名、数字 | 对照锁定稿与真实听音，必要时复用本地 ASR | 只重生成错句，保持声线与发音词表 |
| 语气与节奏 | 同步播放对应镜头/对白 | 调整停连或重生成对应 cue，不截断词尾 |
| 音效与动作 | 对应可观察动作及瞬态位置 | 调整 cue at / source_start 或换匹配声源 |
| 空间与材质 | 实际听音与场景 | 换混响/音效素材，避免所有地点同一声学 |
| 音乐遮蔽 | 人声与铺底一起听 | 降低铺底/改配器/调整 ducking，不用单纯抬高主讲解决全部问题 |
| 循环、拼接、词尾 | 接缝前后及结尾 | 改入出点、淡化或换素材，保留尾音 |
| 双重口播 | 对照混音图层与听音 | 去掉重复源轨，确认 preserve/replace/add_narration 选择 |
| 响度、削波、输出 | 完整解码、重测 LUFS/dBTP | 修新副本并重新测量 |

每个问题记录 cue ID、节目区间、证据、动作、影响范围、before/after 与状态。技术处理最多两轮自动修复，仍失败或未听审保持未完成项。生成失败不能通过合成一个测试音冒充配音、音效或音乐。

交给 video-review-autofix 检查最终 MP4；它的音画流结构检查不能证明口型同步、配音准确或音乐审美通过。向用户只报告实际听过和测过的内容。
