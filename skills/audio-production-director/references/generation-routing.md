# 生成服务路由

这些是本次核对的接口边界。每次执行仍以实际可调用 schema 为准，不能从账户模型列表或其他接口文档推断新增参数。

## 配音

Runway 的 generate_speech 接收 text、预设 voice、model、speed、languageCode、name。当前可调用的 model 是 eleven_v3 和 eleven_multilingual_v2；text 最多 5000 字符，speed 为 0.7–1.2。

- 中性解说、产品说明、稳定长旁白：优先 multilingual 路线，中文 languageCode=zh。
- 角色对白、情绪化旁白：优先 expressive 路线，可使用工具明确支持的括号表演标签；普通舞台说明不要混进朗读文字。
- 声线按用户描述与内容选择，用户没要求浏览时不要抛整张声音列表。预设的英文声线描述不能证明中文口音，必须以真实试听为准。
- 长稿按自然句群分段，保留统一声线、发音词表与情绪衔接。每段生成后实测，必要时把改动限制在错误句。

当前 search_voices 的描述提及 v4 / voiceId，但 generate_speech 的 schema 不接受这些值。除非实际接口已更新，禁止把该组合直接调用。

## 音效

generate_sound_effect 接收 promptText、duration、loop、name。描述最多 450 字符，duration 为 0.5–30 秒；省略时由模型定时长。长环境声需要拆分或明确循环，生成后检查接缝。

简报顺序：声源与材质 → 动作 → 空间与距离 → 起落与尾音 → 是否循环。例如“近距离厚木门缓慢开启，干涩铰链摩擦，狭窄石廊的短混响，结尾自然衰减，无人声无音乐”。

工作区若未启用音效功能，记录不可用并停止该路线；不反复重试同一个拒绝。

## 音乐

generate_music 接收 promptText、model、name，promptText 最多 5000 字符。当前 model 为 lyria-3-clip（短片段、片头、短铺底）和 lyria-3-pro（完整曲目或长配乐）。

没有 duration 参数，模型输出长度固定且需实测。不要声称传入“15秒”文本就保证输出15秒；生成后按剪辑结构选择片段、淡化或明确的循环。音乐生成需要工作区相应付费权限，连接成功和剩余额度不能证明该权限。

简报包含：用途、整体情绪、配器、速度范围、律动密度、段落能量变化、结尾方式、有无歌声、为人声留出的空间。用户要口播铺底时默认纯器乐、克制的主旋律，不机械生成歌曲。

## 完成状态

先用连接检查确认服务身份，不把生成工具的存在当成账户权限已验证。若工具有内嵌预览，按工具要求使用；无预览而需要文件时查询 get_task 到真正完成，复制完整下载 URL。

下载到任务媒体目录，读取并测量文件，记录 cue ID、服务、实际参数、任务状态、source 路径、实测时长与听审结论。未完成、失败或受限时记录 pending / failed / unavailable。

本次只是配置技能，不调用付费生成做任意样片。后续用户要求实际制作声音时沿用任务授权执行；账户限制按工具返回处理，不自动升级套餐。
