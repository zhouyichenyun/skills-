# 配音、音效与配乐制作

统一生成路由加本地混音执行器，适配口播、广告、剧情、Vlog、教程等剪辑需求。

生成端复用已连接的 Runway 配音、音效、音乐工具；实际权限和额度以服务返回为准。仅配置本技能不调用付费生成。本地处理不需要 API Key，也不上传媒体。

阅读 SKILL.md 后使用 scripts/audio.py 完成 probe / mix / mux；scripts/audio_nle.py 将声音交接到已有 FCP7 XML。独立分轨和混音采用 48kHz WAV，可导入 Windows 剪映或达芬奇。

实际生成结果、技术检查、听审和本机软件导入分别记录，不互相冒充。示例只展示计划结构，没有真实生成音频。
