# 与音频制作技能交接

需要补充配音、音效或音乐时，读取已安装的 audio-production-director。不要仅因为口播剪辑已含原声音轨，就认为新配音/配乐已经制作完成。

先完成画面主剪辑和输出时间映射，再按最终节目秒数建立声音计划。新配音是替代原声、补充旁白还是只做片头必须明确，避免两份口播一起播放。原声保留时，可直接把已渲染画面的音轨作为 dialogue；需要替代时，不再把同段原口播放进计划。

音频制作技能实际调用可用服务，生成完成后测量文件，完成对齐、淡入淡出、ducking、响度处理。它输出全节目长度分轨与主混音，不改变本技能已有 job v1 的字段契约。

画面 MP4 与 mix.wav 时长一致后，用 audio.py mux 生成新的合成 MP4，保留视频流。已有 FCP7 XML 可用 audio_nle.py 写入分轨或主混音；默认替换新 XML 副本的原音轨，视频节点保留。音频发生在另一份明确的 audio-plan.json，不向 job.json 塞未实现的 audio_tracks 字段。

最终合成后再次调用 video-review-autofix，复扫实际 AAC 音轨的响度/峰值与音画结构。配音文字、音乐遮蔽、节拍和音效同步需真实听审，不能只检查 WAV 就宣布最终 MP4 通过。
