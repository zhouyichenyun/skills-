# 口播素材的自动选择与生成

从真实转写/剪辑后的输出时间线提取需要展示的证据、动作、场景、产品细节与情绪。每个需求注明输出at/duration/核心主体/不能误导的主张。不是每句话都需要素材；口型、情绪、反应和重要结论可以保留A-roll。

先使用用户提供的素材库。inventory负责ffprobe与关键帧，模型必须查看关键帧再填写主题和实际动作。不可见的文字、产品功能或场景不可根据文件名补齐。对可能误导观众的素材明确区分实拍、示意、重现与AI生成，必要时在画面或说明中标记。

评分表：语义匹配40，主体/证据20，画幅/质量15，时长10，权利/来源15。这里的分数由已观察内容和用户已给的权利依据决定，脚本不假装自动理解画面。任何硬问题（未取得使用权、与主张冲突、关键主体被裁掉、时长不足）直接淘汰或列缺口。

asset-plan按需求保存候选、每项分数、理由、实际路径、是否查看以及最终选择。对AI缺口生成具体制作brief：主体/动作/环境/光线/构图/时长/画幅/连续性/禁止误导事项。已有 cinematic-video-prompt-engineer 可帮助编写真正可执行的生成提示词。

本次用户授权制作素材且对应生成工具可用时，实际调用其能力；先阅读工具说明，不凭文件名猜工具，遵守本次上传和生成权限。制作完成后取得真实文件，查看生成结果，用ffprobe确认尺寸/时长，错误素材修正或弃用。提示词文本、提交成功、排队任务ID均不是已完成媒体。

不在当前任务范围内花费额度，不把需要登录/额度/用户私有库的功能说成已接入。服务不可用时把 status 写为 needs_generation，并先完成无需它的主剪辑。用户后来补齐素材后从缺口续接，不重做已完成的转写与剪辑。

job.broll仅放通过审核且真实存在的素材路径；对于合法的静帧素材，渲染器会持续显示指定时长。AI视频可按source_start裁取，源时长必须够用。默认不使用B-roll自身声音，避免覆盖口播。
